출근 설치 키트

재부팅으로 초기화된 PC에 업무 앱 6개를 다시 설치하는 곳이에요. 모든 파일은 각 회사 공식 서버에서 받아서 항상 최신 버전이 설치됩니다.

한 번에 전부 설치 추천 · 약 3~5분

  1. 아래 버튼으로 설치 파일을 받아요.
  2. 받은 install-all.bat 파일을 열어요.

    "보안 경고"가 뜨면 실행, "이 앱이 변경하도록 허용할까요?"가 뜨면 예. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.

  3. 검은 창에서 설치가 끝날 때까지 기다려요.

    끝나면 결과표가 나와요. 실패한 앱은 다운로드 페이지가 자동으로 열리니 거기서 받아 주세요.

설치 파일 받기
파일 실행이 막혀 있다면: 명령 붙여넣기로 설치
  1. 아래 버튼으로 설치 명령을 복사해요.
  2. 시작 버튼 우클릭 → "터미널(관리자)" → 예.

    단축키는 Win + X 다음 A.

  3. 창에 붙여넣고 Enter.

    여러 줄 붙여넣기 경고가 뜨면 "붙여넣기".

복사됐어요. 터미널(관리자)에 붙여넣어 주세요.
